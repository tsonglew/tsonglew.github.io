阅读官方先修要求与 FAQ ↗
需要什么基础？+

官方要求 CS61 和至少一门研究生级系统课程的基础，并假设你熟悉 Python 与 PyTorch。后半程会频繁用到并发、虚拟内存、缓存、延迟与吞吐量等概念；不要求提前会 CUDA。

有课程视频和中文资料吗？+

官方明确不录制课堂。本站提供中文导航，链接原始英文课件与阅读材料；补充视频可看 Stanford CS336，内容并非 CS2680 的逐讲替代。

没有 GPU，可以开始吗？+

可以先学 Agent 使用、构建与 API 优化。校外自学者需要自行准备工具订阅或 API 额度；课程不向旁听者提供算力。进入模型部署阶段后，再按模型与引擎要求准备计算环境。

资料会一直更新吗？+

本页根据 2026 年 10 月 12 日可访问的课程资料整理，是人工维护的学习导航，不会自动同步课程变更。后续课件、作业与具体要求，以课程官网为准。
