06 / BEFORE YOU ASK

该知道的，
提前说明。

这是服务提供方的官方应用吗？+

Quodex 是 MIT 开源的独立第三方工具，与 OpenAI、DeepSeek、OpenCode、Kimi、WorkBuddy、Cursor 或 Grok 无隶属关系。服务名称仅用于说明连接范围。

数据会实时更新吗？+

Codex 额度支持手动与后台周期刷新；API 与旧版会话连接在前台查询，五分钟内使用缓存；alpha39 开发版的网页登录连接在 App 前台自动更新，五分钟内使用缓存，登录过期或需要验证时暂停并提示处理。后台受 Android 调度、网络与省电策略限制，Token 统计也可能存在服务端延迟，不保证实时更新。

账号数据保存在哪里？+

API 密钥与订阅快照在设备上加密保存；网页登录状态保存在 App 内按服务隔离的浏览器空间，断开时清理。请求直接连接相应服务。Quodex 没有自建数据中转或自动诊断上传；Codex 退出与其他订阅的断开分别处理，本机清理不等于远端撤销授权。阅读隐私说明。

当前隐私说明对应 alpha39 开发版，补充前台自动查询、停止条件与登录验证提示；当前可下载版本仍以 Release 附件为准。 当前下载 alpha38 的隐私说明。 查看 alpha33 随包隐私说明。alpha31／alpha32 的更新检查仅访问 api.github.com，旧版以随包说明为准。查看 alpha32 历史隐私说明。

为什么有些用量显示“未提供”？+

只展示接口实际返回的内容。不同账号、套餐或工作区可能返回不同字段；未知数据不补成零，不从额度百分比推算 Token 或费用。查看支持范围。

桌面组件没有刷新，或尺寸不对？+

先检查网络、省电和 Launcher 权限；强制停止应用期间不承诺更新。升级后桌面可能保留旧尺寸，长按调整或重新添加即可。查看后台指引。

约 12 秒，无声，手动播放。保留 alpha22 发布前的页面淡入、额度填充与柱图动效，其外观不代表当前界面。历史说明与来源。
