还有几个小问题

这是 OpenAI 官方应用吗？

Quodex 是独立的第三方开源工具，与 OpenAI 无隶属关系。Codex 名称用于说明所连接的服务。

数据会实时更新吗？

可以手动刷新，也支持后台周期同步。实际运行时间受 Android 调度、网络与省电策略影响；token 统计可能存在服务端延迟。

我可以查看或反馈问题吗？

可以。在 GitHub 仓库查看源码与发布记录，或前往 Issues报告问题。反馈时请勿附带账号凭据。
