01

额度与重置时间

查看账号返回的额度周期、已用或剩余百分比，以及下一次重置时间。不同账号可用的额度窗口可能不同。

◴
02

桌面，就是仪表盘

标准额度、2×1 紧凑额度和 2×2 的 30 天热力图组件，均支持缩放、主题配置和手动刷新。热力图按七列日历铺满内容宽度，最小尺寸精简文字，把更多空间留给每天的格子。点击图表，直达应用内的 30 日视图。

▦
03

同一份数据，两种看法

近 7 天、30 天都能切换条形图与日历式热力图，并记住你的选择。App 热力图高度随周数调整，保持完整的星期与日期标签。切换保留时间范围与数据，不额外联网；缺失日期和真实零值分别标记。

▥
04

在应用内完成更新

发现新版本后，在 Quodex 内下载 APK、查看进度、取消或重试。校验通过后调起系统安装确认，无需跳转 GitHub 手动下载。

↗
05

用熟悉的语言查看

支持简体中文、English、日本語及跟随系统。页面、小组件、桌面额度图标和更新提示同步切换，浅色与深色界面采用玻璃风格悬浮导航。

文
06

短暂失败，自动再试

额度、Token 统计、更新检查和 APK 下载支持有限次数的重试，并遵守服务端限流。刷新失败保留上次数据，下载中断后重新下载并校验。

还有几个小问题

这是 OpenAI 官方应用吗？

Quodex 是独立的第三方开源工具，与 OpenAI、DeepSeek、OpenCode 或 Cursor 无隶属关系。服务名称仅用于说明所连接的产品。

数据会实时更新吗？

Codex 额度可以手动刷新，也支持后台周期同步；新增订阅查询仅在前台打开订阅页或手动刷新时运行，五分钟内使用缓存。实际后台运行时间受 Android 调度、网络与省电策略影响；token 统计可能存在服务端延迟。

小米手机添加桌面图标或小组件没有反应？

小米、Redmi、POCO 的应用内添加入口会提醒检查“桌面快捷方式”权限，可打开应用信息，再进入权限管理查找该项；系统菜单名称可能不同。提醒不代表应用已检测到权限被拒绝。授权后选择“继续添加”，也可从系统桌面组件列表手动添加。查看权限指引。

升级后热力图组件还是原来的大尺寸？

桌面启动器可能保留旧实例的大小。长按组件缩小，或删除后重新添加，即可使用默认 2×2 布局。

我可以查看或反馈问题吗？

可以。在 GitHub 仓库查看源码与发布记录，或前往 Issues报告问题。反馈时请勿附带账号凭据。
