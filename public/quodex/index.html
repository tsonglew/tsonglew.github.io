CODEX / RESET CARDS

重置卡，
也看得明白。

alpha34 源码新增：在额度页查看可用张数，展开明细看卡片名称、状态、获得时间与到期时间。界面支持中文、English 和日本語。

仅展示，使用卡片请前往 Codex。日期按手机时区显示，实际可用性以服务端为准；不新增后台明细请求。真实账号覆盖仍待验证，发布状态以 Releases 实际 APK 为准。

06 / BEFORE YOU ASK

该知道的，
提前说明。

这是服务提供方的官方应用吗？+

Quodex 是 MIT 开源的独立第三方工具，与 OpenAI、DeepSeek、OpenCode 或 Cursor 无隶属关系。服务名称仅用于说明连接范围。

数据会实时更新吗？+

Codex 额度支持手动与后台周期刷新；新增订阅服务仅在前台查询，五分钟内使用缓存。后台受 Android 调度、网络与省电策略限制，Token 统计也可能存在服务端延迟，不保证实时更新。

账号数据保存在哪里？+

凭据在设备上加密保存，请求直接连接相应服务。Quodex 没有自建数据中转或自动诊断上传；Codex 退出与其他订阅的断开分别处理，本机清理不等于远端撤销授权。阅读隐私说明。

当前隐私说明已包含 alpha34 源码的按需重置卡明细查询。 查看 alpha33 随包隐私说明。alpha31／alpha32 的更新检查仅访问 api.github.com，旧版以随包说明为准。查看 alpha32 历史隐私说明。

为什么有些用量显示“未提供”？+

只展示接口实际返回的内容。不同账号、套餐或工作区可能返回不同字段；未知数据不补成零，不从额度百分比推算 Token 或费用。查看支持范围。

桌面组件没有刷新，或尺寸不对？+

先检查网络、省电和 Launcher 权限；强制停止应用期间不承诺更新。升级后桌面可能保留旧尺寸，长按调整或重新添加即可。查看后台指引。
