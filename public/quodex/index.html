账号信息保存在哪里？+

凭据、API key 与订阅快照使用 Android Keystore 加密保存在设备上。网页登录状态由各服务独立的 WebView 私有目录管理。请求直接连接对应服务，没有自建中转服务或自动诊断上传。阅读完整隐私说明。

用量会自动更新吗？+

Codex 额度支持手动和后台周期刷新。其他服务在 App 前台自动检查，正常缓存五分钟，网页会话过期时需要重新登录。系统省电、网络和服务端限流可能影响更新时间；失败会保留上次数据与时间。

需要先连接 Codex 吗？+

不需要。在“账号”选择你使用的服务，分别连接即可。也可以先体验示例模式；示例模式不发送真实额度请求。Kimi、WorkBuddy 和 Grok / Cursor 的官网登录不需要手工复制 Cookie 或 JSON。

所有 Android 手机和账号都支持吗？+

应用支持 Android 10 及以上。各服务的接口、套餐和登录方式不同，部分服务可能限制嵌入式网页登录。WorkBuddy 目前支持国际站，OpenCode Go 存在接口迁移风险；真实账号和设备覆盖仍在验证中。查看支持范围。

重置卡和 API 福利可以直接使用吗？+

Quodex 只读展示重置卡张数、状态与到期时间，以及 ChatGPT Pro / Business API 福利资格和赠送金额。使用卡片、领取福利与账单管理请前往官方页面。赠送金额不等于消费后剩余余额。
